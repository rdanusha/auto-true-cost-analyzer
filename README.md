# Auto True Cost Analyzer

A free, browser-only tool for comparing the estimated five-year ownership costs of gasoline vehicles. Built by rdanusha.

**Planned public app:** https://rdanusha.github.io/auto-true-cost-analyzer/

**Planned source repository:** https://github.com/rdanusha/auto-true-cost-analyzer

These addresses are release targets, not confirmation that deployment has completed.

## Features

- Compare multiple vehicles with your own purchase, financing, mileage, insurance, maintenance, and fuel-price inputs.
- Five-year total cost, cost breakdown, year-by-year net cost, and cost per mile.
- Fixed-rate loan amortization including remaining debt for loans longer than five years.
- Zero-cost inputs supported. Incomplete or invalid entries show an explanation instead of misleading totals.
- Responsive interface, labeled fields, keyboard controls, and safe handling of vehicle names.
- Illustrative examples, no accounts, no runtime dependencies, and no app analytics.

## Run locally

Open `index.html` directly in a modern browser. No installation or build is required to use the calculator.

Or serve the folder locally:

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

Then open http://127.0.0.1:4178 .

## Development and verification

Node.js 22+ is needed for the tests. Python 3 is used by the test web server.

```sh
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:e2e
```

Playwright is a development-only dependency, not downloaded by app users. Browser tests cover desktop/mobile layout, input validation, safe rendering of vehicle names, adding/removing vehicles, comparison views, zero costs, cash purchases, and long loans. Screenshot generation is included in the browser suite.

## Calculation model

All currency amounts are USD. Distances are miles and fuel is measured in US gallons. Electric vehicles, leases, and currency conversion are not supported.

**Five-year cost = depreciation + interest paid in five years + fuel + insurance + maintenance.**

Equivalent cash-flow formulation:

**Down payment + loan payments made + remaining loan debt + running costs − estimated resale value.**

- Fixed monthly payments and monthly interest, no fees or early repayments. Supported loan terms: 24, 36, 48, 60, 72, and 84 months.
- Generic annual depreciation: 20%, 15%, 12%, 10%, then 9% of the previous year's value. This applies to all entries, including used cars, and may not represent a particular vehicle.
- Maintenance relative to the first-year input: 1, 1.1, 1.25, 1.5, and 1.8.
- Annual mileage, monthly insurance, and gas price are constant. Fuel price is a user assumption, not live market data.
- Annual net cost includes remaining debt and subtracts estimated resale value.
- Cost per mile is unavailable when annual mileage is zero.
- Not included: sales tax, registration, dealer fees, parking, tolls, unexpected repairs outside the maintenance budget, inflation, opportunity cost, or EV charging.

Example figures are illustrative only, not vehicle specifications or insurance/finance quotes. This is an educational planning tool, not financial advice or a guarantee of future costs or resale value.

## Privacy

The app calculates entirely in the browser. It does not send entries to a server, use analytics, or save data in cookies or browser storage. Entries reset on reload. Hosting providers receive ordinary web requests and may log connection information. GitHub source and feedback links navigate to GitHub only when clicked.

## GitHub Pages release

Publish only `index.html`, `styles.css`, `calculator.js`, `app.js`, `social-preview.png`, and `LICENSE`. The included Pages workflow uses an explicit file allowlist. Tests and development files remain in the source repository but not the deployed site artifact.

In repository **Settings → Pages → Build and deployment → Source**, select **GitHub Actions**. The workflow verifies syntax and calculator tests before deploying the public site. It also runs browser checks. The initial release still requires authenticated GitHub access and live URL verification.
