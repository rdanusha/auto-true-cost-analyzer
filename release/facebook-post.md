## Post

Buying a car? The sticker price is only the beginning. 🚗

We built Auto True Cost Analyzer, a free tool to help you compare estimated five-year vehicle ownership costs in one place:

✅ Depreciation and loan interest
✅ Fuel, insurance, and maintenance
✅ Side-by-side comparisons and cost per mile

Enter your own figures and see how the options compare. No sign-up, and your entries stay in your browser.

Try it here: https://rdanusha.github.io/auto-true-cost-analyzer/

The code is open source too: https://github.com/rdanusha/auto-true-cost-analyzer

This first version uses USD, miles, and US gallons for gasoline vehicles. Results are estimates, not financial advice. Taxes and some ownership costs are not included, so check the assumptions in the app.

Give it a try and tell us what would make it more useful.
